# Nordic Frame — Scandinavian Modular Architecture Bureau

Интерактивная веб-платформа с пошаговым конфигуратором модульных домов, расчетом ведомости материалов (BOM), динамическим SVG-чертежом планировки и Telegram-ботом с экспортом сметы в PDF и вызовом инженера по геолокации.

## 🌟 Ключевой функционал

1. **Скандинавский архитектурный минимализм:**
   - Чистый сдержанный дизайн (меловой белый `#F8F9FA`, пепельная древесина `#E9E2D8`, хвоя `#2C423B`, графит `#1F2421`).
   - Архитектурная сетка миллиметровки и векторные чертежи модулей.
2. **Интерактивный конфигуратор префаб-дома:**
   - Базовые модули:
     - **Studio 35м²** (2 450 000 ₽) — компактный дом-студия для загородного отдыха.
     - **Family 65м²** (4 200 000 ₽) — комфортный дом с 2 спальнями и кухней-гостиной.
     - **Villa 110м²** (6 900 000 ₽) — просторная вилла с мастер-спальней и 2 санузлами.
   - Дополнительные опциональные модули:
     - Панорамная терраса из лиственницы (+25м², +480 000 ₽).
     - Финская сауна из канадского кедра (+15м², +750 000 ₽).
     - Панорамное остекление в пол Reynaers (+390 000 ₽).
     - Архитектурная подсветка и сценарии умного дома (+240 000 ₽).
     - Солнечная кровельная электростанция с накопителем (+620 000 ₽).
     - Теплый водяной пол (+180 000 ₽).
3. **Конструктивная валидация и живая смета (BOM):**
   - Сауна и терраса требуют базового модуля (автоматическое добавление Studio 35м² с уведомлением).
   - Расчет статей сметы в реальном времени: каркас и утепление (45%), остекление (15%), инженерия (20%), монтаж и доставка (20%).
   - Динамический SVG-чертеж, визуализирующий планировку модулей на участке.
4. **Генерация официальной PDF-сметы:**
   - Серверный рендеринг официального PDF коммерческого предложения с использованием `ReportLab`.
   - Таблица спецификаций, артикулы, гарантия 25 лет и печать бюро.
5. **Telegram-бот (Aiogram 3.x):**
   - Каталог типовых решений с визуализациями и спецификациями.
   - Автоматическая генерация и отправка PDF-сметы прямо в чат.
   - «Вызов инженера на участок» через отправку Telegram GPS-геолокации с расчетом расстояния и логистики.
   - Диспетчеризация проектных заявок архитектору (@Idrisov_prod).

## 🚀 Запуск проекта

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск веб-приложения и API
```bash
python -m uvicorn backend.app:app --host 0.0.0.0 --port 3015 --reload
```
Веб-интерфейс доступен по адресу: `http://localhost:3015`

### 3. Запуск Telegram-бота
```bash
python -m bot.bot
```

### 4. Запуск тестов
```bash
pytest tests/ -v
```
